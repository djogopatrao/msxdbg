# Changelog

This project follows semantic versioning for its Python package. JSON output
has a separate, explicit schema version.

## 0.11.0rc1 - 2026-09-30

- Package metadata and the `msxdbg` console entry point.
- Python 3.10–3.14 offline CI matrix.
- Formal offline/live test separation and release validation guidance.
- Installation, safety, troubleshooting, compatibility, JSON policy, and
  benchmark documentation.
- Reproducible offline and opt-in live benchmark runner.
- Aggregated repeated project diagnostics with occurrence counts.
- Includes the validated phase 7–10 functionality: project manifests, typed C
  expressions, advanced execution points, contextual image/area resolution,
  and verified memory/register writes.
